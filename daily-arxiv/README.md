# Daily arXiv Radar

A high-threshold daily shortlist of papers from **cs.CV**, **cs.LG / stat.ML**, and **cs.RO**.

Selection principle: **quality over quantity**. Only papers judged genuinely important, technically novel, unusually strong empirically, likely to influence the field, or especially relevant to frontier AI / robotics are included. If nothing clears the bar, the daily note should say so rather than padding the list.

Daily reports are stored as `YYYY-MM-DD.md`.
